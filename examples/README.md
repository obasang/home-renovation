# 比价和跨会话续账示例

全部输入均为虚构材料，金额仅用于验算。

1. 在新会话启用 `home-renovation`，提供 [比价输入](quotes.md)，提问「比较两家目前有依据的价格，给优先约谈对象和报价反转条件」。
2. 在另一个新会话启用 `home-renovation`，提供 [旧台账](ledger-before.md) 和 [新增凭证](new-evidence.md)，提问「更新台账，核对本期应付和重复单据」。

| 检查 | 预期结果 |
| --- | --- |
| 两家报价 | A 补足范围为 118,000 元。B 已知为 116,400 元，含 4,300 元暂估，先谈 B |
| 报价排序变化 | 其余费用相同且 A 不变时，B 水电最终结算 5,900 元时打平 |
| 旧台账 | 水电预计净增 1,675 元，确认净增为 0 元。只有局部复验，二期未触发 |
| 新增凭证 | 书面确认后净增 1,675 元，合同确认价 118,075 元，已付 38,000 元，余额 80,075 元 |
| 二期与差额 | 二期 28,000 元应付未付。差额按合同约定在竣工时结算 |
| 旧行号与重复单据 | 水电净增只有一条计费记录，能查回原行 `C4-WE`、`C4-WE-DELTA`。重复收到 `V-73` 不重复计费 |
