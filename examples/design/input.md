# 两居室客餐厨设计输入

这是虚构的量房案例，所有坐标和尺寸单位为毫米。坐标原点在客餐厨左上角，向右为东、向下为南。只调整客餐厨的家具、材质及与它们关联的点位，其他房间和固定开口沿用现状。

- 客餐厨净范围为 (0,0)–(6400,4300)。卧室一为 (0,4300)–(3000,7200)，卧室二为 (3000,4300)–(6100,7200)，卫生间为 (6400,0)–(8600,2500)，门厅为 (6400,2500)–(8600,4300)。房间框为示意，客餐厨在东侧 y=3000–3800 连到门厅，门厅外门在东侧 y=3250–4150。两个卧室的开口分别在各自北墙 x=800–1700 和 x=4150–5050；卫生间在南墙 x=6850–7650 有门洞。客餐厨北窗为 x=2850–5550。
- 西墙柜台覆盖 x=0–600、y=250–3300。已知水槽中心点 (300,1125)，给排水保留；洗碗机与水槽相邻，柜台内占 y=1500–2100，打开时向东伸出 600。东侧玄关柜已确认，范围 x=4750–6050、y=3650–4100。
- 岛台候选范围 x=1650–2350、y=650–2250。餐桌使用桌面西北角定位，宽向东、深向南。四人桌西北角在 (3500,1200)，宽 1200、深 800。六人桌西北角在 (3100,1350)，宽 1800、深 900。使用时按每一侧椅子向外拉出 500 测算。吊灯拟对准餐桌中心，原点位尚未施工。
- 两位成年人经常一起备菜，喜欢封闭收纳、浅橡木和米白。平时两人吃饭，周末偶尔有六人。希望先看一版带岛台的方案，也想知道去掉岛台值不值得。北窗前布置不动。厨房保留水槽，玄关柜保持原位置和尺寸。现场未核实柜体完成面尺寸、具体洗碗机门扇、吊灯接线及地面材料厚度。

## 复现顺序

1. **初稿请求**：「按这张户型给一版带岛台的客餐厨方案和一版无岛台对照。标出洗碗机打开后岛台旁还能剩多少空间，配一张能看懂布局和材质的效果示意。」
2. **第一轮反馈**：「不要岛台，餐桌改成候选位置的六人桌。玄关柜、北窗和水槽保留。请一起改灯位，看看椅子拉开后东侧还有多少空间。」
3. **第二轮反馈**：「布局定了。只把客餐厨地面改浅灰哑光砖、厨房柜门改暖白。玄关柜保留原木色，视角和点位不变。」
