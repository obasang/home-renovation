# 两居室客餐厨设计示例

这套虚构户型用于比较初稿、按反馈改布局和单独修改材质。每份图稿都包含平面方案、固定视角的轴测效果和交底示意。

## 用 Skill 复现

启用 `home-renovation`，提供 [户型与反馈](input.md)。先发送初稿请求，再依次发送两轮反馈。第二轮也可以在新会话中进行，请一并提供第一轮的方案记录，例如 [V2 参考方案记录](output/v2.json)。对照下表检查结果。

| 图稿 | 核对项 |
| --- | --- |
| [V1 带岛台](output/v1.svg) | 柜台至岛台 1050 mm，洗碗机打开后剩 450 mm。岛台增加约 1.12 ㎡ 台面，压缩了两人一起备菜时的操作通道 |
| [V1-B 无岛台对照](output/v1-b.svg) | 释放岛台占用空间，四人桌、灯位和固定构件与 V1 一致 |
| [V2 布局修订](output/v2.svg) | 取消岛台并换六人桌。东端椅拉出 500 mm 后，至东侧边界净距为 1000 mm。餐桌吊灯从 (4100,1600) 移到 (4000,1800)。玄关柜、北窗和水槽沿用 |
| [V3 材质修订](output/v3.svg) | 只更新效果示意中的客餐厨地面和厨房柜门。两类二维图的几何与点位沿用 V2，效果示意的视角和玄关柜原木色保持一致 |

交底图用于核对点位。灯位接线由电工确认，柜体完成面、洗碗机实际门扇和材料厚度由设计师和现场施工方复核。

## 重新生成参考图稿

在本目录运行下列命令。SVG 图稿可用浏览器打开。生成器只复现这套示例，使用 Python 3.10 或更新版本，依赖标准库。

```sh
python3 render.py
```
