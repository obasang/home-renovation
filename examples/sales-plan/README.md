# 销售户型图和圈注改稿示例

户型、居住需求和圈注均为虚构。图上只有建筑面积，可用于比较布局，不可据此计算室内净尺寸。

1. 启用 `home-renovation`，上传[销售户型截图](sales.png)，提问「两位大人和一个幼儿住，想在客餐区照看孩子。每周在家办公两天，玄关想有封闭收纳，先保留厨房隔墙。还没量房，帮我画两套可以比较的布局，并说我最该去量哪里。」
2. 新开会话，只提供 [V1-A 方案记录](v1-record.md) 和[圈注截图](annotation.png)，提问「把圈里的往箭头方向挪一点，玄关柜别动。给我一张前后对比图，保存新版方案记录。」

| 参考稿 | 核对项 |
| --- | --- |
| [V1-A · 亲子活动优先](v1-a.svg) | 客厅留独立活动区，家长在餐区能照看。办公可先安排在次卧的可用区域，书桌能否放下待量。适合照看幼儿优先的家庭 |
| [V1-B · 餐区兼办公](v1-b.svg) | 餐桌兼办公，办公和照看可同时进行。长桌拉椅后会占用餐区边缘，应先量椅背到通往厨房与入户路线上最近的实体边界 |
| [V2 · 餐桌朝南窗方向微移](v2.svg) | 识别圈中目标为 T01 餐桌，按箭头向南窗方向挪，E01 玄关柜保留。标清旧桌位和新桌位，L01 餐桌灯位跟着方案复核，具体位移和净宽待复尺 |

同一销售户型也可比较[客厅双工位](shared-office.svg)与[次卧独立办公](separate-office.svg)。两张图可以单独打开，侧栏列出了各自的主要取舍。

如果圈注看不清或与已有方案版本对不上，先确认针对哪一版、哪件家具。要复现版本冲突，可以把步骤 2 的记录换成 [V5 方案记录](v5-record.md)，圈注仍然使用 V1-A。两版餐桌原位置不同，先确认使用哪一版底稿。
