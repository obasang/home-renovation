# 住宅设计与审图

根据业主手头的资料推进。有居住需求时给可发给设计师的需求单。有户型图或多个方案时给布局建议和取舍。准备交底时给按工序排序的待确认清单。补问会影响当前决定的信息。

## 把生活习惯写成设计需求

1. 问谁长期住、平时怎么用家、现在哪里最不方便，再补充需要保留的家具设备、预算覆盖范围和入住时间。关注用户实际提到的做饭、办公、照护、收纳、清洁和作息等活动。
2. 把抽象要求写成能在图纸或现场核对的条件。比如「厨房好用」可落实为两人同时备菜、常用小家电有固定位置、洗碗机打开时仍能操作水槽。让业主标出必需、希望有和可取舍的事项。
3. 用一页简报交付居住场景、优先级、必留物品及已知尺寸、预算和待量房事项。用户谈风格时，请其指出参考图中喜欢的颜色、材质或光线，和设计师确认哪些做法会影响预算或维护。

## 看户型和比较方案

- 核对资料是销售户型图、现场量房图、平面布置图、施工图还是效果图。记录图纸版本、已有尺寸和已知位置。在图中定位门窗、梁柱和管井等约束。尺寸未标或版本冲突时，写明要复尺的位置。避免用平面截图的像素推算可施工尺寸，或凭墙线粗细判断承重。
- 按同一组居住需求看每个方案。把家具、设备、开门和抽屉一起看，沿实际路径检查进出、做饭、洗衣或夜间使用。按需比较收纳、自然光、通风、噪声和隐私。偏好可通过不同摆位或材料实现时，说明每种做法会牺牲什么。
- 结合现场条件判断实施代价。查水电、排水、吊顶、柜体及设备安装是否要改，指出多做的工程和需要单独询价的项。拆改、燃气、外立面等约束按 [装修规则核验](rule-verification.md) 处理。把原结构未核实的方案标为待专业确认，直接给可先深化的布局方向。
- 给每个方案最影响选择的优点、代价和未决条件。能推荐时说明推荐建立在哪些假设上，以及哪项复尺或报价会改变选择。只有效果图时，先讲能观察到的布置和使用问题，再列出可用于确认的带尺寸平面图或节点图。

## 开工前审图

对照同版本的平面布置、相关施工或柜体图、设备安装要求和报价。每条问题写清所在房间和图纸、冲突或缺项、由谁复核、最迟在哪道工序前决定，以及确认后要更新哪份图纸或报价。

| 节点 | 优先确认 |
| --- | --- |
| 拆改前 | 现状与拆改范围、保留构件、结构和公共设施的核验结果 |
| 水电交底前 | 洁具、电器和家具定位，开关插座、照明、进排水及柜体接口。厨卫设备尚未定型号时，先明确安装条件及谁负责最终核对 |
| 泥木施工或下单前 | 完成面尺寸及门洞、地面高差、吊顶检修空间和柜体复尺。按产品及施工顺序确认下单所需尺寸 |
| 设计变更后 | 同步影响的图纸、供货分工、报价与工期。请相关施工方和供货商确认手里是同一版 |

例如，高柜方案能放下更多小家电，但缩短连续备菜台面。若每天做饭且两人常同时操作，先深化保留连续台面的方案，并要求设计师标出可用台面长度、洗碗机门打开后的净通道及进排水位置。请橱柜商在水电交底前和设计师对同一版图，尺寸以现场复尺和所选设备的安装资料确认。
