# 装修公司筛选与比选

## 先知道业主需要谁

结合城市和服务区域、交付时间、面积口径、预算覆盖范围、需要做的空间、业主能投入的时间筛选。需要新找公司时，优先补问影响名单的城市或区、预算及其范围。用户只想知道怎么选时，可直接给筛选与看工地的方法。

模式还没决定时，先按 [装修模式选择](renovation-models.md) 对照管理投入、选材和分工。结合业主对预算、工期、设计和投入时间的优先级，用 [统一询价模板](quote-and-ledger.md) 整理给各候选公司的工程范围。

## 从本地线索核对到可约谈对象

1. 用户要具体公司时，联网查当地门店及经营主体。品牌官网和本地门店渠道用于确认品牌自述、服务区和联系方式。同小区交付案例、本地地图和评价用于发现候选及回访问题。记录链接、日期和信息是谁发布的。
2. 按企业全称或统一社会信用代码核验拟签约主体。核对宣传门店、签合同、收款、开票、施工和保修由谁负责。品牌、分公司、加盟商与实际施工方需要分别对上。查[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)的登记状态、经营异常或相关行政处罚。项目要求特定资质或商家声称具备资质时，通过[全国建筑市场监管公共服务平台](https://jzsc.mohurd.gov.cn/home)或当地主管部门核验证书主体、范围和有效性。先查该项目适用的资质要求。
3. 以服务范围相符、主体可辨和有可追溯的本地线索为入围依据。拟签约主体、具体报价或实际团队尚未明确时，写成待核实。官网案例、平台评分和单条评论分别注明性质。官方查询受限时，给用户企业全称或查询入口，并说明核验缺口。没有相符候选时，给搜索路径和统一询价简报，避免编造或凑数。

当前无法联网时，明确具体门店尚未检索。先提供本地找候选的方法和可直接使用的询价简报，并继续比较用户已提供的材料。

推荐具体公司时，用少量候选逐家列出门店或主体、匹配理由、核验过的事项、风险或缺失证据、下一步要问的问题，以及能打开的出处。按现有证据给约谈优先顺序，最终签约建议取决于量房报价、实际团队及合同。项目地址和联系方式等资料由用户自行决定何时向商家提供。

## 用同一套做法比现场和合同

| 看什么 | 怎么取证和比较 |
| --- | --- |
| 谁负责干活 | 见拟派项目经理或工长，确认哪些工序分包、现场谁管、出现问题找谁以及换人的约定 |
| 工地做得怎么样 | 经同意看拟派团队的在施工地，优先看即将隐蔽的工序、成品保护和验收记录。看完工项目时问整改与售后如何响应 |
| 总价是否可控 | 发同一份需求，要求确认包项、品牌型号、用量、工程量计算、超量价和必做未含项。按 [报价核对](quote-review.md) 换算到相同范围 |
| 签了以后怎么兑现 | 看报价和图纸是否作为合同附件，材料替换是否需确认，增减项如何定价并书面确认，付款和哪些验收节点挂钩，工期、整改和保修由谁承担 |

把用户的硬要求和风险放在总价之前核对。签约主体讲不清、收款与合同不符且无书面依据、拒绝提供分项报价或回避书面变更的，指出卡点和所需证据。两个候选可比较时，说清首选、备选以及哪条待核实事项会改变顺序。

可发给候选公司：「我家是毛坯交付，位于［区］，［建筑或套内面积］，计划［时间］开工。请按附件的工程范围和编号回填报价，标注材料规格、数量、超量单价和不含项目。方便的话，请一并发拟签合同主体、付款与验收节点、保修安排，以及拟派工长负责的可预约在施工地。」
