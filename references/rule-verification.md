# 装修规则核验

从用户问的动作入手，例如「物业要求交这笔钱」「工长说防水必须这么验」「这笔水电加价是行业规定」。先定位发生地、住宅和改造类型、工程部位、装修阶段，以及谁提出要求。有通知、合同、图纸或检测材料时，定位原文与版本。

| 要核实的内容 | 查什么 | 回答时说清什么 |
| --- | --- | --- |
| 能不能施工、谁审批、物业如何报备 | 现行法律法规和部门规章，当地住建、房管或街道的正式文件，物业书面流程 | 哪个主体负责，哪些情形适用，要办什么手续和准备什么资料 |
| 做法、材料、试验和验收 | 现行工程建设强制性规范、适用的验收标准、确认图纸、合同及产品安装要求 | 条款适用的部位、工法和阶段，谁来测、怎么确认、留什么记录 |
| 物业限制、收费或退还 | 小区装修管理协议和收费明细、当地官方规定及相应依据 | 发起方、收费事项、书面依据及退还条件。物业口头通知可用于确认线索 |
| 报价、计量、变更、工期、付款和保修 | 已签合同及附件、书面变更单、可核实的履约记录，涉及法定权利义务时再查适用法规 | 商家报价口径与合同约定分别是什么，数量和费用怎样复核，争议还缺哪份资料 |

优先查发布机关原文。核对条款号、地域、实施时间、现行状态和修订替代情况。明确哪些内容有强制要求、哪些因合同或设计引用而适用、哪些属于施工建议或商家口径。只看到标题、老版本、二手解读或照片时，将结论限定在证据能支持的范围，给出官方查询入口或下一步核实方法。给具体尺寸、时长、公差或费用标准前，先核对条款适用条件。

中国大陆国家层面可从[住房城乡建设部规章库《住宅室内装饰装修管理办法》](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2023/art_17339_775528.html)及当地主管部门官网开始。仍需检查修订和地方要求。承重、燃气、强电、公共设施等事项先确认图纸、现场及专业核验要求。物业同意、工长经验或相邻住户的做法分别只能证明其对应事实。

答复交付「目前能判断的结论、适用对象及依据、还要谁确认、业主现在该做的事」。比如工长称「行业标准要求水电按米加钱」，请对方提供标准名称及条款，核对条款是否涉及施工做法、验收或计量。是否应另付钱还要查套餐范围、合同计量与变更条款，再请施工方提供路线、测量记录、所用单价与已有费用扣减。无法验证合同或当地规定时，先给核查问题。
