# 阶段检查与沟通

用合同约定、确认图纸、项目做法、产品安装说明和当地现行要求确定检查项。施工排程根据现场与工艺调整。重点确认下一道工序会不会挡住检查，以及问题由谁在什么时候复验。

| 阶段 | 业主现在要确认的事项 | 可留存的凭证 |
| --- | --- | --- |
| 毛坯收房 | 对照购房合同及交付附件核实现状。记录门窗启闭、墙地顶裂缝和渗水痕迹、可检查的给排水点及表底数，沟通交付缺陷由谁整改、何时复看。涉及签收效力、交付条件或整改争议时核对当地规则及已签文件 | 交付资料、带位置和日期的照片、问题与整改交接单 |
| 需求与量房 | 房屋现状和缺陷、使用需求、预算包含范围、入住时间、物业施工要求、设备和家具的尺寸约束 | 现场原貌照片、尺寸图、关键需求 |
| 设计与签约 | 按 [住宅设计与审图](design-review.md) 确定布局和待复尺事项。核对图纸和报价是否对得上，明确关键做法、材料规格和替换规则、供货安装接口、增减项、付款条件、工期和保修责任 | 双方确认的同版图纸、报价和合同附件 |
| 拆改与交底 | 拆改范围及核验依据、现有管线和保留项、对相邻部位的保护、拆除后新增问题，厨卫设备与水电点位 | 交底记录、现状照片、书面变更及工程量 |
| 水电及防水 | 封闭前核对点位、走向和测试记录。防水覆盖前核查阴阳角、管根和门口等细部，按适用要求安排试验和记录 | 可定位的走线和细部照片、试验记录、整改复验单 |
| 泥木油及安装 | 铺贴、找坡、收口、吊顶检修与安装预留，柜体复尺和门扇开合空间，产品型号及安装条件 | 材料确认单、复尺图、工序验收及整改照片 |
| 竣工交接 | 通水排水、设备和门窗实际使用、外观与收口、结算工程量、遗留项、保修联系方式 | 竣工验收单、结算与变更明细、保修和设备资料 |
| 入住与保修 | 对照合同和产品保修查报修渠道、责任主体和处理节点。新出现的渗漏、开裂或设备故障按位置和时间保存记录 | 报修回执、处理及复验记录 |

## 现场问题怎么记录

用「位置 + 可见情况 + 照片或视频 + 约定或检测依据 + 负责人 + 复验时间」记录。用户发来照片时，协助圈定要复看或测量的位置，并指出下一道工序之前要拿到的记录。明确何时需要现场专业测量。检查具体公差、试验方法或法规时查当前适用的正式来源，避免直接套用网络流传的统一数值。

准备毛坯收房、水电封闭、防水覆盖，或被催缴阶段款时，用 [现场检查与阶段付款](site-checks-and-payments.md) 将现场问题关联到复验和对应的台账记录。

## 消息示例

- **发给设计师**：「麻烦在同一版图纸上标出洗碗机尺寸、开门空间、进排水和电源位置，并注明柜体与设备分别由谁复尺。请确认好再把这一版发给水电工和橱柜商。」
- **发给工长**：「明天封槽前，麻烦提前约个时间一起核对点位和管线走向，并把相关测试记录和每面墙能定位的照片发我。现场发现的问题请记到验收单里，约好整改和复验时间。」
- **发给装修公司**：「请把这笔增项对应的原合同条款、位置、数量和单价逐行发我，同时列出原项目应扣减的金额，以及对完工日期的影响。争议部分如果还没施工，请先确认能否暂停，等双方书面确认后再排期。」
