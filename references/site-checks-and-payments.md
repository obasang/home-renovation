# 现场检查与阶段付款

## 现场检查卡

按用户即将到达的节点给一张卡。将检查项写成可在现场勾选的短条目。记录房间、检查结果、照片或测量记录、整改人、复验时间，以及下一道工序。用户给的照片仅记录可辨认的现象。试验、尺寸、公差和验收依据按 [装修规则核验](rule-verification.md) 核对实际项目。

### 毛坯收房

- **去之前**：带购房合同的交付附件、户型图和交付通知。向交付方确认同行人员、现场通水通电条件及缺陷登记方式。
- **业主现场看**：按房间记录墙地顶裂缝或水迹、门窗启闭和玻璃外观、可见给排水点及水电表读数。每处问题拍能定位的全景和近照。
- **请现场人员核查**：按约定说明可试用的设备和管路。疑似渗漏、结构异常或需要通电、通水测试的情况，记录现象，约交付方或专业人员查验。
- **离场前**：请交付方书面确认房间位置、问题、对接人和复查安排。暂未检查的项目单独列出。询问签收前提或拒收影响时，查合同及适用规则。

### 水电封槽、封板或回填前

- **带什么**：最新确认的水电点位图、涉及的柜体及设备安装资料。先问清计划覆盖的部位和时间。
- **业主现场看**：逐间用图纸对照开关插座、给排水点和可见管线走向。尤其核对厨卫设备和柜体接口。拍房间全景、整段走向和问题近照，画面带门洞、墙角等参照，或在图上编号。
- **请施工方或约定的验收人员核查**：对点位偏差现场定位并测量。按项目适用要求组织水路和电气测试，由专业人员操作并提供含位置、测试条件、结果和确认人的记录。
- **需整改时**：把有问题的部位、负责人、整改方案和复验时间写进记录。与施工方确认该部位覆盖前的复验和施工安排。费用另核原范围、变更依据及实际工程量。

### 防水被覆盖或贴砖前

- **带什么**：确认的防水施工范围、部位做法和材料资料。问清试验计划，以及下一工序时间。
- **业主现场看**：请施工方指认管根、地漏周边、墙地交接和门口等细部。记录覆盖前的现状、材料型号及可见异常。
- **请施工方或约定的验收人员核查**：确认适用的试验部位、方法、条件和判定依据。留存试验起止和观察结果。应查下层或相邻部位时，提前协调进入条件。可从 [住房城乡建设部防水规范公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2022/art_17339_768499.html) 查到标准入口，再核实适用条文。
- **发现异常时**：记录现象及试验条件，确认谁负责排查和整改，并在约定复验后记录结果。下层无法查看或试验资料缺失时，保留实际核验范围与待办。

## 配合台账核对阶段款

1. **找触发条件**：定位已签合同及附件中的对应条款。核对触发的是进场、某工序完工、验收确认、固定日期还是其他条件，并查验通知、签认、复验及书面变更的约定。
2. **查实际发生了什么**：核对该阶段验收记录、验收范围、遗留问题和复验结果。单个整改部位通过时记为局部复验，合同要求整阶段签认时，继续核对覆盖范围和对应签认凭证。若合同另约定分区验收、分段付款或其他触发方式，按对应条款和证据判断。条款、记录或整改影响不清时，将付款条件标为待核对。需要比对条款写法时，可参考 [市场监管总局合同示范文本库](https://htsfwb.samr.gov.cn/View?id=e3f51fe0-cdb4-4382-bfa4-64e3c784b9c6)。
3. **复算本期金额**：核对该期固定金额或计费基数、已付抵扣、已确认增减项是否应在本期结算，以及付款对象。合同余额和本期应付分开记录。合同、增项和验收的证据分别记录，避免把一项待核对直接推断为整笔款可付或可拒付。
4. **给业主可执行的反馈**：说明哪一项条件已有证据、哪一项还差材料、谁在何时补齐。按 [装修台账](quote-and-ledger.md) 关联付款、验收、整改和费用编号。需要协调时给可发消息。

## 封槽前发现点位偏差并被催款

演示输入。工长说明天封槽，厨房洗碗机插座位置与已确认点位图 V2 不符。合同约定水电阶段验收确认后付二期款。总合同价 109,000 元，含水电暂估 5,000 元且按差额结算。工长口头报水电最终金额 6,800 元，无书面确认。

- **当天现场检查**：带点位图 V2 和设备资料，让工长、设计师与橱柜商按各自分工核对插座和安装位置，拍带定位参照的照片。索取覆盖部位的适用测试记录，确认整改和复验时间。
- **台账更新**：水电费用先标「单方报价」，预计净增 1,800 元，合同当前确认价为 109,000 元。双方书面确认后更新原记录，合同当前确认价为 110,800 元。若厨房插座整改复验通过，只更新对应整改项。整阶段验收签认留在独立记录中，二期应付按合同条款及其对应凭证核对。
- **可发给工长**：「厨房洗碗机插座现场位置和 V2 图有出入，麻烦先保留这一处，约设计师和橱柜商一起复核，整改后我们再确认覆盖时间。请把水电测试和工程量记录、单价、原合同里已含的 5,000 元及本次差额发我。二期款我会按合同的水电验收确认节点核对，请一并发验收单和付款明细。」
